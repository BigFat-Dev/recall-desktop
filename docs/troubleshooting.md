# 故障处理

| 现象 | 检查方法 |
| --- | --- |
| 找不到官方 Codex CLI | 启动官方 Codex，只保留一个运行副本；Recall 按其实际安装位置发现组件。组件缺失时更新或重新安装宿主，开发覆盖见技术说明。 |
| 已开启权限但仍提示未授权 | 核实当前程序路径、签名是否改变；回到设置检查当前构建，不以旧开关代替验证。 |
| 按保存快捷键没有反应 | 查看 Recall 设置中的快捷键冲突提示；指针需在已完成消息正文上，Codex 需在前台。 |
| 正文边界无法核验 | 可能为特殊渲染、内容未完整加载或宿主结构变化。待生成结束后重试；工具不会保存局部段落冒充全文。 |
| 已有权限，但首次采集只读到滚动区域 | 新版先通过公开应用角色初始化正文辅助功能，并在原位置有限重试。仍失败时提供详情中的节点关系计数、命中状态和版本；不要上传正文，也不要反复撤销授权来处理正文读取故障。 |
| 原消息修改、删除或重复 | 返回会明确停止。重新确认原消息后保存新标记，不建议重复点击期待跳到相似结果。 |
| 返回因切换应用而停止 | 返回期间保持 Codex 前台；取消或焦点变化后只在仍可核验所有权时清理本次查找栏。 |
| 剪贴板保护失败 | 先妥善保存当前剪贴板内容，再尝试普通文字；工具在无法完整保留格式或超过 64 MiB 时先停止。 |
| 中断后剪贴板仍为链接或宿主复制结果 | 取消后会短暂等待已发出复制的清理。若面板出现“剪贴板恢复”，可确认恢复操作前内容，或保留当前内容。快照只在本次进程内，退出前处理；详见隐私说明。 |
| 自己导出的备份无法恢复 | 0.3.3 已移除 64 MiB 文件门槛并在后台校验。若仍失败，请保留原文件并检查格式、可用内存/磁盘与完整错误；不会跳过校验或强制覆盖。 |
| 本地保存失败 | 保留编辑框草稿，查看错误详情；检查文件权限、磁盘空间和是否有另一个实例改写文件。 |
| 主文件损坏 | 先保留损坏文件，通过设置选择有效备份恢复；恢复仍会验证格式与并发修改。 |
| 长对话较慢 | 首次计算、当前宿主响应和消息渲染均会影响速度。已定位不等于核验结束；不能省略证明来加速。 |

返回失败面板的“查看详情”提供原错误和结构诊断。本地最新数字计时在数据目录的 `last-return-performance.json`，不含正文、备注或对话标识。公开反馈前仍应检查内容；不要上传整份数据目录。

请使用 Issue 模板提供版本、虚构复现和脱敏错误。安全问题遵循 [安全报告说明](../SECURITY.md)。
