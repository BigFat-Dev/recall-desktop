# Recall Desktop

作者：[BigFat-Dev](https://github.com/BigFat-Dev)

在桌面应用中的 Codex 或 ChatGPT Work 对话里保存一整条消息和一句备注，点击标记卡片后直接返回原对话中的对应消息，并短暂高亮。

这是独立运行的 macOS 桌面伴侣和菜单栏面板。当前支持 **Apple Silicon Mac 上同一桌面宿主应用内的 Codex 和 ChatGPT Work**，不需要浏览器扩展或额外云账号。

## 当前状态

当前公开预览版为 [v0.3.3](https://github.com/BigFat-Dev/recall-desktop/releases/tag/v0.3.3)，可从版本页面下载 DMG 和校验文件。包含浅色 A / 深色 C 应用图标。0.3.3 已在一台 Apple Silicon Mac 上由使用者确认重新授权后的整条消息保存、跨对话定位、高亮与查找栏关闭正常；项目作者也已在本机多次实测确认 ChatGPT Work 可用，见[验证记录](docs/validation.md)。其他机器的首次安装和未来宿主版本仍需验证。本项目与 OpenAI 无隶属关系，兼容性可能随宿主版本变化。

- 保存整条用户消息或 AI 回复，并填写备注。
- 查看摘录、来源、时间，修改备注或确认删除；删除后可短时撤销。
- 点击卡片自动打开原对话、定位原消息、关闭本次查找栏并高亮约 2.5 秒。
- 数据本地保存，支持更改已有内容前自动备份、导出和确认恢复。
- 重复标记同一消息时打开原备注；无法核验原消息时明确停止。

应用图标提供浅色 A、深色 C。已在 macOS 27.0.1 验证“外观 → 图标与小组件样式 → 深色 → 自动”随系统浅深色切换；其他样式由系统决定。实现包含 macOS 26+ 的原生外观资源，以及 macOS 14/15 的运行中 Dock 回退；14/15 的 Finder 和退出后保留浅色。26 和更旧系统尚未实机验收，设置名称也可能不同。

暂不支持选中文字、图片/附件、AI 摘要、标签、文件夹或跨设备同步。

## 从源码构建

需要 Apple Silicon Mac 和包含原生图标编译器的完整 Xcode，不能只安装 Command Line Tools。已验证工具链为 Xcode 27.0、Swift 6.4；其他工具链版本未验收。测试另需 Python 3.8+。详见 [验证记录](docs/validation.md)。

在本仓库根目录运行：

```sh
./test.command
./build.command
```

应用生成于 `build/Recall Desktop.app`。将它复制到你选择的本地应用目录，再按 [安装与授权说明](docs/installation.md) 启动。构建脚本不安装应用、不操作真实宿主、不修改现有标记或授予系统权限。

默认使用临时开发签名，重建后可能需要重新授权。可以使用自己的已有本地签名身份，见 [开发说明](CONTRIBUTING.md)。本仓库不提供私人证书、钥匙串或密码，也不把本地开发签名称作 Apple 公证。

## 使用

1. 启动宿主桌面应用与 Recall Desktop，进入 Codex 或 ChatGPT Work 对话，按提示检查并手动授予辅助功能权限。
2. 在 Codex 或 ChatGPT Work 中，把指针停在一条已完成消息的正文上，按 **⌘⇧M**。
3. 确认采集的是整条消息，填写一句备注并保存。
4. 按 **⌃⌥B** 或点击菜单栏入口，调出标记面板。
5. 点击标记卡片，自动返回原消息；右上角“⋯”可修改备注或删除。

返回期间让宿主桌面应用保持前台，可从 Recall 面板或菜单栏取消。快捷键冲突会显示提示。详见 [故障处理](docs/troubleshooting.md)。

## 定位与精度

保存时通过公开辅助功能读取正文，使用宿主“复制对话深链接”取得对话身份，再通过宿主随附的本地 App Server 只读接口取得消息身份与原文。返回使用对话链接和宿主查找；当前没有消息级原生深链接。

高亮前必须核验原消息身份、原文/作者、最新完整历史中的唯一性、界面完整正文和最终可见坐标。无法确认、消息被修改/删除或存在重复位置时停止，不按相似内容猜测。

接口初始化启用了 `experimentalApi` 能力标志。公开接口、宿主安装布局与辅助功能结构均可能变化；这些依赖不构成长期稳定性承诺。宿主组件自动发现及开发用环境变量覆盖方法见 [技术说明](docs/architecture.md)。

本实现需要目标对话支持 `thread/items/list` 历史分页；不支持该读取方式的历史会明确失败，不自动迁移或修改宿主数据。

## 本地数据与隐私

主文件：`~/Library/Application Support/Recall Desktop/bookmarks.json`。自动备份在同目录 `backups/`，目标保留最近 20 份；清理旧备份失败时可能更多。

标记及备份含完整已保存消息、备注和定位信息，未加密；不是只保存摘要。旧版数据迁移会保留原文件。其他历史内容仅用于本机内存核验。数字诊断不含正文、备注、标题或对话标识。

本工具没有对话上传、账号登录、云同步或模型调用功能。宿主自身的网络行为与隐私策略由宿主决定，本工具不声称能控制它们。剪贴板会在取得对话链接期间临时使用，并有格式与版本保护。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 已知限制

- 已发出的复制请求会在有限观察期内完成链接接管及清理，取消后可能短暂等待。无法确认的结果不自动覆盖；原剪贴板暂存于本次进程内，可在面板“剪贴板恢复”菜单中选择恢复或保留当前内容，退出后释放。
- 备份导入、校验及恢复在后台进行，不再有 64 MiB 的文件大小门槛，仍受本机内存、磁盘及有效数据格式约束。剪贴板快照的 64 MiB 保护容量保持不变。
- 新建目录会申请限制性权限，但既有目录不会自动收紧；数据与备份未加密，详见隐私说明。
- 新开发构建可能需要重新授予辅助功能权限；当前 DMG 尚无 Developer ID 签名或 Apple 公证。
